# Google Search Console setup

Site: **https://autobookagency-art.github.io/the-systems-edge/**
Sitemap (auto-generated by `jekyll-sitemap`): **https://autobookagency-art.github.io/the-systems-edge/sitemap.xml**

## Step 1 - Add the property

1. Go to https://search.google.com/search-console and sign in.
2. Click **Add property** and choose **URL prefix** (not "Domain" - you don't own the `github.io` DNS).
3. Enter exactly: `https://autobookagency-art.github.io/the-systems-edge/` and click **Continue**.

## Step 2 - Verify ownership (pick ONE method)

Google generates a unique token for you, so it can't be created in advance. Use either:

### Option A: HTML file (recommended)
1. In the verification dialog choose **HTML file** and download the file Google gives you (named like `google1a2b3c4d5e6f7890.html`).
2. Copy it into the **root of this repo** (next to `_config.yml`), unchanged.
3. Publish it:
   ```
   git add google*.html
   git commit -m "Add Search Console verification file"
   git push
   ```
4. Wait about a minute for GitHub Pages to rebuild, open `https://autobookagency-art.github.io/the-systems-edge/google1a2b3c4d5e6f7890.html` in a browser (it should show the file's text), then click **Verify** in Search Console.

### Option B: HTML meta tag
1. In the dialog choose **HTML tag** and copy the value of `content="..."`.
2. Put it in `_config.yml`:
   ```
   webmaster_verifications:
     google: PASTE_THE_CONTENT_VALUE_HERE
   ```
3. Commit and push as above, wait for the rebuild, then click **Verify**. (`jekyll-seo-tag` adds the tag to every page.)

Do not delete the verification file / tag afterwards, or ownership will lapse.

## Step 3 - Submit the sitemap

1. In Search Console, left menu: **Indexing -> Sitemaps**.
2. Under **Add a new sitemap** type: `sitemap.xml` (the part after the property URL).
3. Click **Submit**. Status should change to **Success** (can take a few minutes to a day).
4. To check the file is live first, open `https://autobookagency-art.github.io/the-systems-edge/sitemap.xml` - it should list the homepage, About, Guides and every post.

## Step 4 - Ask Google to index the posts faster (optional)

Use the **URL inspection** bar at the top, paste a post URL, and click **Request indexing**. Do this for the 6 posts. Indexing can still take days to weeks, and a new site on a `github.io` project path starts with little authority.

## Notes

- `robots.txt` only works at a domain root, so the one Jekyll generates under `/the-systems-edge/` is ignored by Google. That's fine - nothing here is blocked, and you submit the sitemap by hand as above.
- A custom domain (Settings -> Pages) would be better for SEO long term; if you add one, create a new Search Console property for it and update `url` / `baseurl` in `_config.yml`.
